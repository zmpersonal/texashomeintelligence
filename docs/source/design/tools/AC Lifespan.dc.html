What we'd do in your position

Get a refrigerant check before next April, and don't authorize a big repair without it.

A 2011 install is on the R-410A/R-22 boundary. If it's R-22, a compressor or coil repair can cost more than a third of a replacement, which changes the math well before the unit fails.

Three questions to ask whoever you call
  1. What refrigerant is in this system, and what does a pound of it cost right now?
  2. What's the measured static pressure, and is the duct sized for the tonnage you're quoting?
  3. Is this quote a like-for-like changeout or a system redesign, and what's the difference in price?

How this is calculated

We match your address to the county appraisal record and the city's mechanical permit history, then measure the last system-replacement permit against expected service life adjusted for local cooling load. Where no permit exists we fall back to year built, which is a weaker signal and is labeled that way everywhere it appears.

Open question · address autocomplete provider

The field is designed provider-agnostically: one oversized input, manual entry always reachable, and an attribution row reserved at the bottom of the suggestion list. Switch the Autocomplete provider tweak to see the two divergent renderings. Six things change downstream:

  1. Attribution. Places requires the provider logo inside the list; Smarty does not. The row is reserved either way so the list height doesn't change between builds.
  2. Multi-unit timing. Smarty returns a unit count with the suggestion, so the multi-unit screen can fire before submit. Places reveals nothing until Place Details resolves, so that screen must also work post-submit. Both paths are designed.
  3. Unit entry. Smarty can prompt for a secondary designator as a structured second field; Places needs a free-text unit line. Not yet drawn — flagging it.
  4. “No suggestions” meaning. With Smarty it is a real signal the address isn't deliverable, which justifies a caution above manual entry. With Places it's weak, so the copy stays neutral. Current screen is written for the neutral case.
  5. Latency. Places needs a second Details call before we can geocode, which adds a confirm beat the loading narration has to absorb. Smarty returns components with the pick.
  6. Outside-Texas frequency. Smarty filters server-side, so that state is rare. Places can only bias, so it will happen often and needs to stay gracious.

Same divergence applies to roof-scan, pipe-report, and storm-check.
